Datasets

Combine several files

Train scripts/train_models.sh on several files at once (like --files), for example labelled tunnels plus benign traffic. Pick files from the project's data/ folder and uploaded datasets. Nothing is copied: the new dataset is just a list of the files.

2. Train

Training creates a candidate model. It never changes production.

Labels

Advanced settings — leave closed to use the train_models.sh defaults

This file is trained with the train_models.sh standard (as Path A): per class 72 % train / 14 % validation / 14 % test, outliers capped at the training 0.1 % / 99.9 % quantiles, gradient-boosted trees with isotonic calibration, and an alarm threshold at ≤ 0.1 % false alarms on benign validation rows. Every row is read; if memory is short, all attack rows and a weighted sample of benign rows are used (shown in the run log).

This changes the test set, so results are not comparable with earlier runs.
